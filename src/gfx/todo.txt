────────────────────────────────────────────────────────────────────────────────
 LEGEND
────────────────────────────────────────────────────────────────────────────────

  Y        Implemented and functional.
  ~        Stub — function exists and is wired, but does nothing useful.
             Calls gfx_stub_not_implemented() or is an empty scaffolding body.
             Safe to call (no crash), but has no effect.
  N        Missing — no implementation exists and pfn slot is null.
             Calling the public API will crash (null function pointer).
  /        No-op by design — the concept does not apply to this backend.
             E.g. explicit barriers are not needed in Metal / WebGPU.
  [n]      Footnote — see NOTES section for details on the deviation.
  [W]      Warning logged at runtime, operation skipped.
  ~[1]     Stub AND subject to footnote [1] (DX12 scaffolding-only backend).

 API SURFACE (gfx.h)
────────────────────────────────────────────────────────────────────────────────

CONTEXT / DEVICE
  gfx_init                         - create context (instance, device, queues)
  gfx_get_caps                     - query gpu caps (texture compression, rt, etc.)

SWAPCHAIN
  gfx_create_swapchain             - create window surface + swapchain
  gfx_acquire_img                  - get next backbuffer render target
  gfx_present_img                  - present to screen

RESOURCE CREATION
  gfx_buffer_create                - vertex / index / uniform / storage / indirect
  gfx_shader_create                - from spirv (vk/wgpu) or MSL source (metal)
  gfx_sampler_create               - filter + address mode + anisotropy
  gfx_texture_create               - 2d / cube / array / 3d + compressed formats
  gfx_pipeline_create              - raster pipeline (vs+fs + vertex layout + render states)
  gfx_compute_pipeline_create      - compute shader pipeline
  gfx_render_target_create         - offscreen render target (color + depth attachments)
  gfx_descriptor_set_create        - binding set per shader
  gfx_cmd_create                   - command buffer

RESOURCE DESTRUCTION
  gfx_buffer_destroy
  gfx_shader_destroy
  gfx_sampler_destroy
  gfx_texture_destroy
  gfx_pipeline_destroy
  gfx_render_target_destroy
  gfx_descriptor_set_destroy
  gfx_cmd_destroy
  gfx_compute_pipeline_destroy

BUFFER / TEXTURE UPDATES
  gfx_buffer_update_data           - cpu -> gpu (staging copy or mapped)
  gfx_texture_update_data          - [WIP] update texture region via staging
  gfx_texture_get_data             - [WIP] readback texture to cpu
  gfx_texture_generate_mipmap      - [WIP] auto-generate mipmaps
  gfx_texture_blit                 - [WIP] copy / blit between textures

SHADER UNIFORMS / BINDINGS
  gfx_uniform_location             - lookup binding handle by name
  gfx_uniform_set_buffer_data      - write ubo fields inline (mapped)
  gfx_uniform_set_buffer           - bind storage / ubo buffer object
  gfx_uniform_set_texture          - bind texture to set
  gfx_uniform_set_sampler          - bind sampler to set
  gfx_shader_get_uniforms          - enumerate shader uniforms  [BROKEN: assert(false)]

COMMAND BUFFER
  gfx_cmd_begin                    - start recording
  gfx_cmd_begin_pass               - begin render pass
  gfx_cmd_end_pass                 - end render pass
  gfx_cmd_end                      - stop recording

  gfx_cmd_scissor                  - set scissor rect
  gfx_cmd_viewport                 - set viewport

  gfx_cmd_bind_pipeline            - bind raster pipeline
  gfx_cmd_bind_descriptor_set      - bind uniform/texture/sampler set
  gfx_cmd_bind_index_buffer        - bind index buffer (16/32 bit)
  gfx_cmd_bind_vertex_buffer       - bind vertex buffer to slot

  gfx_cmd_draw                     - non-indexed draw
  gfx_cmd_draw_indexed             - indexed draw
  gfx_cmd_draw_indexed_indirect    - gpu-driven indexed indirect draw

  gfx_cmd_dispatch_compute         - dispatch compute shader

  gfx_cmd_push_marker              - debug label push (GPU timeline)
  gfx_cmd_pop_marker               - debug label pop

  gfx_cmd_buffer_barrier           - explicit buffer memory barrier
  gfx_cmd_texture_barrier          - explicit texture layout/memory barrier

  gfx_texture_update_bindless      - [WIP] update bindless descriptor table entry

SUBMIT / SYNC
  gfx_cmd_submit                   - submit cmd with wait options (idle/fence/queue)
  gfx_submit                       - [MISSING] submit + return fence  (declared, unimpl)
  gfx_wait                         - [MISSING] wait on fence          (declared, unimpl)

UTILITY
  gfx_utils_thread_id
  gfx_utils_stack_trace / stack_trace_names
  gfx_utils_hash_16

================================================================================
 NOTES
================================================================================

[1]  DX12 is scaffolding only. All functions allocate empty structs; no real
     D3D12 calls are made. Logs "DX12 backend is stubbed" on init.

[2]  wgpu_get_caps not wired up in gfx.cpp (pfn_get_caps left null for WebGPU).

[3]  Logs error: "wgpu_create_compute_pipeline not implemented" /
     "wgpu_create_render_target not implemented". Sets output to null.

[4]  Metal function has empty body ({}). No resource allocated / freed.

[5]  gfx_compute_pipeline_destroy implemented. Vulkan: real cleanup via gfx_pool_free
     + vkDestroyPipeline. Metal/WebGPU: stubs (create is unimplemented, nothing to free).
     DX12: free() stub consistent with other DX12 scaffolding.

[6]  Metal update_buffer_data works only for Shared/Managed storage mode.
     Private (GPU-only) buffer path stubs with gfx_stub_not_implemented.

[7]  metal_uniform_set_buffer: validation only, no actual binding recorded.
     metal_uniform_set_sampler: handle validated but sampler not written to set.

[8]  gfx_shader_get_uniforms in gfx.cpp is assert(false). Not routed through
     pfn table at all.

[9]  metal_cmd_begin_pass has hardcoded clear color (0.3, 0.6, 0.9, 1.0).
     Clear color should come from gfx_render_pass_desc_t.

[10] metal_cmd_draw / metal_cmd_draw_indexed hardcode MTLPrimitiveTypeTriangle,
     ignoring topology from pipeline state.

[11] vk_cmd_draw_indexed_indirect implemented via vkCmdDrawIndexedIndirect.
     Wired in gfx.cpp Vulkan table.

[12] wgpu_cmd_draw_indexed_indirect emulates multi-draw via loop (N calls).
     WebGPU spec doesn't guarantee multi-draw in one indirect call.

[13] vk_cmd_buffer_barrier and vk_cmd_texture_barrier implemented using
     vkCmdPipelineBarrier2 (Vulkan 1.3 synchronization2). Uses get_vulkan_state()
     to map gfx_barrier enum to VkPipelineStageFlags2 / VkAccessFlags2 / VkImageLayout.

[W]  wgpu_texture_generate_mipmap logs a warning and returns. WebGPU has no
     native mipmap generation command. Requires a custom downsample pass per level.
